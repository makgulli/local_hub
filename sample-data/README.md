# sample-data (로컬 개발용 목업 데이터)

이 폴더의 JSON은 **실제 공공데이터가 아닌, SCHEMA.md 구조를 그대로 따라 만든 소량의
가짜(mock) 데이터**입니다. 실제 JSON 파일을 아직 전달받지 못한 상태에서 화면/기능을
빠르게 확인하고 싶을 때 아래처럼 복사해서 사용하세요.

```bash
cp sample-data/*.json public/data/
npm run dev
```

⚠️ 실제 배포/제출 시에는 반드시 회사가 제공한 정식 `구미_경북권_*.json` 데이터로
교체해야 합니다. 이 mock 데이터에는 좌표·주소가 실제와 다르게 임의 생성되어 있습니다.
